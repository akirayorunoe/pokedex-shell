# Project Pokedex

A simple project to practice:
- Infinite loading
- react-query
- Virtualization using [@tanstack/react-virtual]()
- Webpack
- Module Federation

To run local
Change remote path in vite.config.js to your local path and run:
```
run build && npx vite preview
```

[Demo](https://akirayorunoe.github.io/pokedex-shell/)
